# 隐私说明

TTS WebUI Workbench 是本地优先的桌面工具，不提供由项目维护者运营的中转服务。

## 本地保存

应用会在本机保存模型配置、声音配置、任务历史、生成音频和用户选择的参考音频。便携发布包只含空数据目录，不包含维护者的配置或素材。

## 何时发送到外部

- 使用 Dummy、Piper 或本地服务时，数据按相应本地配置处理。
- 使用 Higgs 或其他云端 TTS 时，文本、参数以及完成合成所需的参考音频会直接发送给用户配置的提供商。
- 使用翻译预处理时，待翻译文本会发送给用户配置的 OpenAI-compatible 接口。
- 未配置或未调用云端功能时，应用不会为了遥测主动上传这些内容。

第三方提供商的保留时间、训练政策、地域和计费不由本项目控制。敏感文本和声音在上传前应由用户自行确认授权与风险。

## 删除与备份

界面可以删除部分历史、配置和关联文件。卸载应用不一定会自动删除应用数据目录；彻底删除前应先关闭程序，再手动清理本机应用数据。升级、迁移或清理前请自行备份。

## 日志和问题报告

错误日志可能包含第三方工具返回的信息。公开分享前应删除密钥、私人文本、声音、用户名和绝对路径。
